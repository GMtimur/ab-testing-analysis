# Данные

Источник: [A/B Testing — Kaggle](https://www.kaggle.com/datasets/zhangluyuan/ab-testing).

Публичный учебный датасет, опубликованный пользователем zhangluyuan на Kaggle.
Сравниваются старая и новая версии страницы.

Поля: `user_id`, `timestamp`, `group`, `landing_page`, `converted`.

Для запуска скачайте и распакуйте датасет,
затем поместите файл `ab_data.csv` в эту папку.

Исходный CSV исключён из Git через `.gitignore`.
Условия использования указаны на странице источника.
